# kirath25.github.io

The root of the HUX GitHub Pages address. `index.html` sends visitors to https://kirath25.github.io/hux-website/ and `404.html` shows a HUX 'page not found' screen for unknown addresses. Both forward HUX account e-mail links (`#access_token=…` / `#error=…`) to https://kirath25.github.io/hux-website/account/.
